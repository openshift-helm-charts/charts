Zainar LCS ({{ .Chart.Name }} {{ .Chart.Version }}) is installed in namespace {{ .Release.Namespace }}.

This chart matches the docker-compose stack:
  controller :4000/:4001/:4002/:4003/:4004
  lmf-pe     :8080/:8081/:8888/:9878
  amf-proxy  :8082
  zps-light  :9094/:9095
  db         :5432

1. Loki wait is off by default (`global.waitForLoki=false`). Set it true only
   when Service `loki:3100` is already in this namespace.

2. Port-forward UIs:

   kubectl -n {{ .Release.Namespace }} port-forward svc/controller 4003:4003
   kubectl -n {{ .Release.Namespace }} port-forward svc/zps-light 9094:9094 9095:9095

3. Change secretEnv values (API keys, SECRET_KEY_BASE, DB password) before production.

4. Keep LOCATION_PROVIDER=namf unless you have a reason to talk to LMF directly.
   Direct nlmf callbacks to the controller (HTTP 204) crash lmf-pe.

5. Stuck in Init (Init:0/2)? That is wait-for-dependencies, not migrate:

   kubectl -n {{ .Release.Namespace }} logs deploy/controller -c wait-for-dependencies
   kubectl -n {{ .Release.Namespace }} logs deploy/lmf-pe -c wait-for-dependencies

   Full catalog: docs/troubleshooting.md in the zainar-helm-charts repo.
